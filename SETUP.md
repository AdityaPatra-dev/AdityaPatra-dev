# 🚀 Aditya Patra — GitHub Profile 2.0

This bundle turns the profile README into an automated visual system.

## 1. Repository

Use the public profile repository:

`AdityaPatra-dev/AdityaPatra-dev`

GitHub displays a profile README when the repository is public, has the same name as your username, and contains `README.md` in its root.

## 2. Copy everything

Copy this bundle into the root of the profile repository. The generated `output/` and `profile-3d-contrib/` directories will appear after the Actions run.

## 3. Push

```bash
git add .
git commit -m "feat: build automated GitHub profile"
git push origin main
```

## 4. Run the workflows once

GitHub → repository → Actions → run:

- GitHub Profile 3D Contributions
- Contribution Snake
- Profile Telemetry

## 5. Optional profile setting

If you want anonymized private contribution activity included in your contribution graph, enable GitHub's private contribution visibility setting.
